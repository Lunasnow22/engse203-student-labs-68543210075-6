# CP41 — ทางเลือกฐานข้อมูล

คำตอบนี้จัดทำโดยมี AI ช่วยร่างจากโค้ดจริง ตามรายละเอียดใน AI_USAGE.md ผู้จัดทำควรทบทวนและปรับถ้อยคำให้ตรงกับความเข้าใจของตนก่อนส่งและอธิบายในคลิป

## 1. ทำไมโปรเจกต์นี้เลือก SQLite แทน MongoDB

ข้อมูลของระบบมีโครงสร้างชัดเจน ได้แก่ผู้แจ้งในตาราง users และคำร้องในตาราง requests ซึ่งเชื่อมกันด้วย requester_id จึงเหมาะกับฐานข้อมูลเชิงสัมพันธ์อย่าง SQLite ที่ใช้ JOIN ดึงชื่อผู้แจ้งพร้อมรายละเอียดคำร้องได้โดยตรง
SQLite มี foreign key, constraint และ transaction ช่วยตรวจความถูกต้องและทำให้การสร้างผู้แจ้งกับคำร้องสำเร็จหรือย้อนกลับพร้อมกัน
ระหว่างพัฒนาสามารถเก็บเป็นไฟล์และรันได้โดยไม่ต้องติดตั้ง database server แยก
MongoDB เป็นฐานข้อมูล NoSQL แบบ document ที่ใช้กับข้อมูลนี้ได้เช่นกัน แต่โจทย์นี้ยังไม่มีความจำเป็นต้องเปลี่ยนรูปแบบการเก็บข้อมูล ส่วนการ deploy เลือก Turso เพื่อเก็บข้อมูลแยกจากเครื่อง Render โดยใช้ SQL เดิมต่อได้

## 2. ถ้าเปลี่ยนเป็น MongoDB จะกระทบชั้นไหนบ้าง

ชั้น service ต้องเปลี่ยนจาก SQL และ prepare().get()/all()/run() เป็นคำสั่งของ MongoDB รวมถึงออกแบบ document, ความสัมพันธ์ และวิธีรักษาความถูกต้องของข้อมูลใหม่
MongoDB driver ติดต่อฐานข้อมูลแบบ async จึงทำให้ controller ต้อง await ผลลัพธ์จาก service ก่อนตอบ HTTP และส่งข้อผิดพลาดเข้า error handler
ในโค้ดนี้ userRoutes เรียก service โดยตรงด้วย จึงต้องปรับ route เหล่านั้นให้รอ Promise เช่นกัน รวมถึงขั้นตอนเปิดการเชื่อมต่อและ health check
Frontend สามารถใช้ต่อได้หาก API ยังคืนชื่อฟิลด์และ HTTP status ตามสัญญาเดิม เช่น requesterName และ id โดย service แปลงรูปแบบข้อมูลให้ตรงกัน

## 3. async จำเป็นเมื่อไร และไม่จำเป็นเมื่อไร

async/await ใช้เมื่อ API ที่เรียกคืน Promise เช่น fetch หรือ MongoDB driver เพื่อรอผลโดยไม่บล็อก event loop ระหว่างงาน I/O
SQLite ในโปรเจกต์นี้ใช้ DatabaseSync ซึ่งคืนผลโดยตรง จึงไม่จำเป็นต้อง await แต่ละ query แม้การ query นั้นจะบล็อก thread ระหว่างทำงาน
Turso อยู่บนเครือข่าย แต่แพ็กเกจ libsql ที่เลือกในใบงานมี interface แบบ synchronous จึงใช้ query เดิมได้ โดย openDatabase เป็น async สำหรับ dynamic import
ดังนั้นการเลือกใช้ async ไม่ได้ขึ้นกับตำแหน่งฐานข้อมูลอย่างเดียว ต้องดู interface ของ driver และภาระงานด้วย หากต้องรองรับคำขอพร้อมกันจำนวนมากควรพิจารณา driver แบบ async และวัดประสิทธิภาพจริง
